**Self-Rating Evaluation Approval Flow Issue**

Findings

When an AP Staff submits a self-rating evaluation, the request is immediately visible to both the Branch Supervisor and all Branch Managers. This is incorrect because the approval process should follow a sequential workflow.

Current issues identified:

1. After AP Staff submits a self-rating evaluation, all Branch Managers can already view the request before the Branch Supervisor reviews it.
2. Branch Managers are able to approve the request even though the Branch Supervisor has not yet approved it.
3. When a Branch Manager rejects the request, it is routed directly to HRD instead of being returned to the employee for revision.
4. The approval workflow is being bypassed because higher-level approvers can act on requests that should still be pending at lower approval levels.

Expected Approval Flow

Rank-and-File Employee Self-Rating

Employee → Branch Supervisor → Branch Manager → HR Supervisor → HR Manager (Final Approver)

Branch Supervisor Self-Rating

Branch Supervisor → Branch Manager → HR Supervisor → HR Manager (Final Approver)

Branch Manager Self-Rating

Branch Manager → Branch Supervisor → HR Supervisor → HR Manager (Final Approver)

Expected Behavior

* When an employee submits a self-rating evaluation, only the immediate next approver should receive and view the request.
* Branch Managers should not receive, view, approve, or reject the request until the Branch Supervisor has approved it.
* Each approval stage should only become available after the previous approver has completed their action.
* If any approver rejects the request, it should be returned to the employee for correction and resubmission, not forwarded to HRD.
* The system should enforce the approval hierarchy and prevent higher-level approvers from acting on requests that have not yet reached their approval stage.
