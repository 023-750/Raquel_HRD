Evaluation Types:

> Annual
> Quarterly
> Initial
> Final

Those Evaluation Types should be based on the employee's Date of Hire, Employee Status.

For example:

Template Evaluation Type selected to Annual
Employee Status: Regular
Date Range: Every 1 year based on the applicable evaluation date.

Template Evaluation Type selected to Quarterly
Employee Status: Probationary
Date Range: Every 3 months based on the applicable evaluation date.

Template Evaluation Type selected to Initial
Employee Status: Newly Hired / Probationary
Date Range: One-time evaluation based on the employee's hiring or probation start date.

Template Evaluation Type selected to Final
Employee Status: Exit / For Separation
Date Range: One-time evaluation based on the employee's exit/separation date.

Important: We need to discuss whether the evaluation schedule should always be based on the Date of Hire, or if certain evaluation types should use a different reference date.

For example:

Annual → based on Date of Hire or Regularization Date
Quarterly → based on Date of Hire or Probation Start Date
Initial → based on Date of Hire
Final → based on Exit/Separation Date

We also need to determine what should happen when an employee's status changes from Probationary → Regular, because the system needs to know when to stop the Quarterly evaluations and start the Annual evaluation schedule.

Discuss this further with the client before finalizing the evaluation automation and database structure.
